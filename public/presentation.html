BuildLex AI 발표 요약

건축법규 검색과 근거 기반 AI 답변을 결합한 교육용 웹 애플리케이션

BuildLex AI는 사용자가 건축 설계와 인허가 과정에서 생기는 질문을 입력하면, 국가법령정보센터에서 현행 법령과 지역 건축조례를 검색하고 관련 조문만 Gemini에 전달해 답변을 생성하는 교육용 웹 프로젝트입니다.

프로젝트 목적

  • 실무자가 설계 초기 단계에서 확인해야 할 법규 범위를 빠르게 찾습니다.
  • AI가 일반 지식으로 임의 답변하지 않고 검색된 조문 안에서 답하도록 제한합니다.
  • 답변과 함께 법령명, 조문, 시행일, 국가법령정보센터 원문 링크를 제시합니다.

검색과 답변 생성 과정

  1. 질문에서 용도지역, 건폐율, 용적률, 주차, 피난, 방화, 구조 등 핵심 주제를 판별합니다.
  2. 주제에 맞는 건축법, 국토계획법, 주차장법과 관련 시행령 및 시행규칙을 선택합니다.
  3. 국가법령정보센터 API에서 각 법령의 현행 조문을 동시에 조회합니다.
  4. 입력 지역이 있으면 해당 지역의 건축 조례도 추가로 검색합니다.
  5. 질문어와 확장 키워드의 일치도를 계산해 관련도가 높은 조문 8개를 선정합니다.
  6. 선정된 조문만 Gemini에 전달해 결론, 적용 근거, 추가 확인사항 순서로 답변합니다.

현재 검색 범위

건축법 3단계, 국토계획법 3단계, 주차장법 3단계, 피난 및 방화 규칙, 구조기준 규칙, 입력 지역의 건축 조례

핵심 구현과 개선점

항목일반적인 간단 구현BuildLex AI
법규 데이터미리 가공한 CSV 데이터베이스국가법령정보센터의 현행 법령 API
질문 확장Gemini가 전문용어와 법령명을 추출고정 주제표와 키워드 규칙으로 검색계획 생성
조문 선정키워드 포함 여부와 밀도 점수질문어에 가중치를 주고 제목과 본문 일치도 계산
답변 범위자료가 부족하면 Gemini 일반지식 사용 가능검색 조문에 없는 수치나 예외는 추측 금지
출처 표시법령 링크와 용인시 행정 페이지 연계조문명, 시행일, 법령 원문 링크 표시
실행 구조Python과 StreamlitNext.js와 Vercel

개선한 부분

  • CSV 갱신 없이 현행 법령을 조회하므로 최신 시행 조문을 확인하기 쉽습니다.
  • 검색 단계를 규칙 기반으로 구성해 같은 질문에 대한 검색 결과를 재현하기 쉽습니다.
  • Gemini는 최종 답변에만 사용하므로 API 호출 횟수와 응답 지연을 줄였습니다.
  • 일부 법령 조회가 실패해도 나머지 검색 결과로 답변을 계속 생성합니다.
  • 검색된 근거 밖의 수치와 조문을 추측하지 못하도록 프롬프트를 제한했습니다.

현재 부족한 부분과 이유

법규 관계망 조례가 위임받은 상위법과 조문이 다시 인용하는 법규를 재귀적으로 추적하려면 별도 관계 데이터와 반복 조회가 필요합니다.

행정정보 용인시 담당 부서와 홈페이지 안내는 법령 API에 포함되지 않아 별도 사이트맵 수집과 지속적인 갱신이 필요합니다.

의미 확장 Gemini를 검색 전 단계에도 사용하면 유사어 검색은 좋아질 수 있지만 비용, 지연, 결과 변동이 커집니다.

조례 범위 도시계획, 주차장, 경관 조례까지 확대하려면 중복 제거와 조례별 검색계획이 추가로 필요합니다.

검색 개수 Vercel 실행시간과 법제처 API 응답시간을 고려해 법률 최대 8개, 근거 조문 최대 8개로 제한했습니다.

발표용 설명 대본

저희 프로젝트는 건축 실무자가 설계와 인허가 과정에서 법규를 빠르게 확인할 수 있도록 만든 BuildLex AI입니다. 사용자가 지역과 질문을 입력하면 국가법령정보센터의 현행 법령과 지역 건축조례를 검색하고, 질문과 관련도가 높은 조문만 골라 Gemini에 전달합니다.

미리 저장한 법규 CSV 대신 현행 법령 API와 규칙 기반 검색을 사용했습니다. 이 방식은 검색 결과를 재현하기 쉽고, 오래된 데이터 파일을 수동으로 갱신해야 하는 부담을 줄입니다.

질문 속 핵심 단어와 건축 주제를 분석한 뒤 관련 법률을 최대 8개까지 동시에 조회합니다. 이후 질문어와 조문 제목 및 본문의 일치도를 계산해 상위 조문 8개를 선정합니다. Gemini는 이 조문만 근거로 답변하며, 근거가 없는 수치나 예외를 추측하지 않도록 제한했습니다.

현재 버전은 발표용 MVP이므로 법규 관계망과 용인시 담당 부서 안내는 제외했습니다. 앞으로 도시계획조례와 주차장조례를 확대하고, 조문 속 인용 법령을 자동 추적하면 설계 실무에서 더 깊은 검토가 가능해집니다.

시연 질문

  • 용인시 제2종 일반주거지역에서 다세대주택을 신축할 때 대지 안의 공지 기준과 인접 대지경계선 이격거리 기준을 설명해주세요.
  • 용인시 일반주거지역 공동주택의 정북방향 일조권과 채광방향 이격거리 기준은 어떻게 되나요?
  • 용인시 비도시지역 대지는 도로에 2m 이상 접해야 하나요?

시연 시 확인할 사항

  • 관련 법률 주제와 근거 번호가 올바르게 표시되는지 확인합니다.
  • 시행일과 국가법령정보센터 원문 링크가 함께 제공되는지 확인합니다.
  • 실제 인허가는 관할 허가권자 확인이 필요하다는 점을 설명합니다.
