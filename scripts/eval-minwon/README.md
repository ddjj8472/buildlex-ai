# 실제 민원(법제처 법령해석례 60건) 평가

- 평가셋: `tests/minwon.json` — 건축법 관련 법제처 해석례 60건(질의요지·회답·이유·관계법령).
- 실행: 사이트(브라우저 콘솔)에서 `/api/ask`에 질의요지를 그대로 넣고, `holdout`으로 같은 해석례를 근거에서 제외(정답 유출 방지).
- 채점: 결론이 법제처 회답과 일치하면 C, 반대면 W, 판단 유보 H, 생성 실패 F. 법령 개정으로 회답이 현행법과 달라진 2건(3번: 건축법 제60조④ 2022 신설, 31번: 제61조② 개정)은 X로 제외 → 58건 기준. `grades.json`에 건별 기록.

- 오프라인 검색 재현(`ret_eval.mts`): 질문이 지목한 핵심 조문 포함 46 → 55/56.

## 남은 오답 유형 (두 실행 모두 오답: 8, 10, 18, 25, 30, 33, 45 등)
입법 취지·체계 해석으로 문언과 다른 결론을 내는 해석례(예: 부칙의 '건축허가'에 대수선허가 포함, 준용 범위 확장, 단서의 적용 범위). Magesh et al.(2024)의 reasoning error, 법령 조사 벤치마크의 "예외 규정 오독"과 같은 유형으로, 검색이 아니라 추론 단계의 한계.
