# BuildLex AI

건축 관련 질문을 받으면 국가법령정보센터의 현행 법령·자치법규를 검색하고, 관련도가 높은 조문만 Gemini에 전달해 근거 중심 답변을 만드는 교육용 MVP입니다.

## 구현 원칙

검색 로직과 웹 애플리케이션 코드는 이 프로젝트의 요구사항에 맞춰 독립적으로 작성했습니다. 외부 코드를 포함하게 될 경우 해당 라이선스와 고지 의무를 따릅니다.

## 검색 범위

- 건축법·시행령·시행규칙
- 국토의 계획 및 이용에 관한 법률·시행령·시행규칙
- 주차장법·시행령·시행규칙
- 건축물의 피난·방화구조 등의 기준에 관한 규칙
- 건축물의 구조기준 등에 관한 규칙
- 사용자가 입력한 시·군·구의 건축 조례
- 공동주택관리법·시행령·시행규칙 및 주택건설기준 등에 관한 규정
- 질문에 따라 주택법·건설산업기본법·도시 및 주거환경정비법과 하위 법령
- 해당 지역 도시계획·주차장 설치 및 관리·주택 조례(정확한 조례명이 일치할 때만 선택)
- 검토하여 수록한 용인시 공개 민원 회답 6건과 접도 관련 법제처 회답 1건

판례·법령해석례 전체 검색과 소방·장애인·교육·환경 등 개별법 전체는 포함하지 않습니다. 수록한 공개 회답은 회신·게시 시점과 현재 법령을 구분하여 참고하며, 원문 출처를 표시합니다.

## 검색 로직

1. 질문의 핵심 단어와 건축 주제를 로컬 규칙으로 확장합니다.
2. 주제에 맞는 법령 목록을 정합니다.
3. 법제처 API에서 현행 본문을 가져옵니다.
4. 한국어 조사·띄어쓰기와 동의어를 정규화하고, 조문 제목 가중치 및 검색 집합 내 단어의 희소성을 반영합니다. 명시한 법률·조문, 사안별 직접 조문을 우선합니다. 주차대수 질문은 주차장 자체의 용도변경과 구별합니다.
5. 이미 조회한 자료 안에서 조문이 명시적으로 인용한 다른 조문을 한 단계 연결하고 최대 10개의 근거를 선택합니다. 지역·시설·행위 조건이 맞는 공개 회답도 별도로 검색합니다.
6. 서버가 원문 문구에 번호를 부여하고 Gemini가 각 판단을 뒷받침하는 근거·문구 번호를 JSON으로 선택합니다. 서버가 실제 원문으로 연결하여 문구 번호·수치 존재를 검사한 뒤 화면용 답변과 인용을 구성합니다. 모델의 인용 복사 실수를 줄이며, 의미상 적용은 별도 AI 재검토와 실제 회신 비교로 확인합니다.

Gemini는 답변 생성과 적용 대상·근거 재검토에 총 2회 사용합니다. 기존 무료 키와 설정된 모델을 유지하며, 1회 생성보다 호출량이 늘어납니다. 인용 문구 일치 검사는 의미상 올바른 적용을 보장하지 않으므로 공식 회신과의 실제 답변 비교도 별도로 수행합니다.

답변은 현재 판단, 적용 조건과 근거, 부족한 정보, 다음 확인사항으로 구성합니다. 마크다운 강조 기호를 제거합니다. 원문 문구·수치 검사는 허구의 근거를 줄이는 제한적 검사이며, 문구가 결론을 논리적으로 지지하는지나 법적 정확성 전체를 보증하지 않습니다. 근거 번호를 누르면 조문 카드로 이동하고 발췌 내용을 펼쳐볼 수 있습니다.

조회 실패, 미수집 별표, 긴 조문의 발췌 여부를 표시합니다. 별표 본문 자동 수집은 아직 포함하지 않으며, 공개 회답에서 안내한 별표 기준과 현재 별표 원문을 혼동하지 않도록 지시합니다. 검색할 법령을 임의로 8개로 자르던 제한은 제거했습니다.

## 품질 확인

AI 과부하·응답 실패·근거 번호 검증 실패 시에도 검색된 조문과 원문 링크를 보존합니다. AI 검토 미완료임을 명시하며, 자동 안내문을 법적 판단으로 표시하지 않습니다. 원문 링크는 공식 상세 링크를 우선 사용하고 없으면 검색한 개정 일련번호의 공개 법령·조례 뷰어로 연결합니다.

`npm test`와 `npm run build`로 확인합니다. `tests/baseline-search.ts`는 비교용 기존 검색 구현입니다. 가상 조문 8문항의 Top-1 평가는 특정 검색 오류를 재현하는 회귀 검사이며, 실제 법률 답변 정확도 점수가 아닙니다.

## 로컬 실행

```bash
npm install
cp .env.example .env.local
# .env.local에 GEMINI_API_KEY 입력
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## API 키

Google AI Studio에서 새 Gemini 키를 만들고 `GEMINI_API_KEY`에 넣습니다. 키는 브라우저 코드에 들어가지 않고 Next.js 서버 라우트에서만 읽습니다. `.env.local`은 `.gitignore`에 포함되어 GitHub에 올라가지 않습니다.

법제처 API는 미설정 시 공식 문서의 발표용 `OC=test`로 작동합니다. 안정적으로 배포하려면 국가법령정보 공동활용 사이트에서 이용 신청 후 발급받은 OC를 `LAW_API_OC`에 넣으세요.

## Vercel 배포

1. 이 저장소를 Vercel에서 Import합니다.
2. Project Settings → Environment Variables에 다음을 추가합니다.
   - `GEMINI_API_KEY`
   - `GEMINI_MODEL=gemini-3.1-flash-lite`
   - `LAW_API_OC` (정식 신청 전에는 `test`)
3. Deploy를 누릅니다.

API 키를 `NEXT_PUBLIC_...` 이름으로 만들거나 GitHub 파일에 직접 적지 마세요.

## 주의

이 앱은 교육용 검색 보조 도구이며 법률 자문이나 인허가 가능성을 확정하지 않습니다. 실제 프로젝트는 대상지의 용도지역·지구, 건축물 용도·규모, 지자체 조례와 관할 허가권자의 해석을 추가 확인해야 합니다.
