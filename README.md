# BuildLex AI

건축 관련 질문을 받으면 국가법령정보센터의 현행 법령·자치법규를 검색하고, 관련도가 높은 조문만 Gemini에 전달해 근거 중심 답변을 만드는 교육용 MVP입니다.

## 구현 원칙

검색 로직과 웹 애플리케이션 코드는 이 프로젝트의 요구사항에 맞춰 독립적으로 작성했습니다. 외부 코드를 포함하게 될 경우 해당 라이선스와 고지 의무를 따릅니다.

## 검색 범위

- 공동주택관리법·시행령·시행규칙과 API가 제공하는 별표 본문
- 집합건물의 소유 및 관리에 관한 법률
- 질문 의도 분석으로 찾아 API에서 정확한 명칭이 확인된 추가 국가법령
- 건축법·시행령·시행규칙
- 국토의 계획 및 이용에 관한 법률·시행령·시행규칙
- 주차장법·시행령·시행규칙
- 건축물의 피난·방화구조 등의 기준에 관한 규칙
- 건축물의 구조기준 등에 관한 규칙
- 사용자가 입력한 시·군·구의 건축 조례

판례·법령해석례와 지자체 민원 사례 DB는 현재 자동 수집하지 않습니다. 개별법은 질문 의도에 따라 추가 조회하며 모든 법령을 항상 전수 검색하지 않습니다.

## 검색 로직

1. 질문을 로컬 규칙으로 분류하고 Gemini의 구조화된 의도 분석으로 관련 법령명·전문용어를 확장합니다. 의도 분석이 실패하면 규칙 검색으로 계속합니다.
2. 주제에 맞는 법령 목록을 정합니다.
3. 법제처 API에서 현행 본문을 가져옵니다.
4. 한국어 조사·띄어쓰기와 동의어를 정규화하고, 조문 제목 가중치 및 검색 집합 내 단어의 희소성을 반영해 중복을 제거한 상위 12개 조문·별표를 고르고 인용된 별표를 추가 연결합니다. 공동주택 행위허가와 일반 건축허가를 구분합니다. 주차대수 질문은 주차장 자체의 용도변경과 구별합니다.
5. 선택된 조문만 Gemini에 전달하고, 답변에 `[근거 n]` 표시를 강제합니다.

Gemini를 검색 의도 분석과 최종 해석에 사용합니다. 법률 용어의 일반 설명은 허용하되, 근거가 없는 수치·예외·조문을 확정하지 않습니다. 확인된 조건별 원칙을 먼저 설명합니다.

답변은 현재 판단, 적용 조건과 근거, 부족한 정보, 다음 확인사항으로 구성합니다. 마크다운 강조 기호를 제거하며 근거 번호의 존재와 범위를 검사합니다. 이 검사는 답변의 법적 정확성이나 인용 내용의 일치까지 보증하지 않습니다. 근거 번호를 누르면 조문 카드로 이동하고 발췌 내용을 펼쳐볼 수 있습니다.

조회 실패, 근거가 인용했지만 확보되지 않은 별표, 매우 긴 근거의 발췌 여부를 표시합니다. 도시계획·주차장 조례와 별표는 아직 수집하지 않습니다. 검색할 법령을 임의로 8개로 자르던 제한은 제거했으며, 최종 답변은 상위 12개 근거와 연결된 별표를 사용합니다.

## 품질 확인

AI 과부하·응답 실패·근거 번호 검증 실패 시에도 검색된 조문과 원문 링크를 보존합니다. AI 검토 미완료임을 명시하며, 자동 안내문을 법적 판단으로 표시하지 않습니다. 원문 링크는 공식 상세 링크를 우선 사용하고 없으면 검색한 개정 일련번호의 공개 법령·조례 뷰어로 연결합니다.

`npm test`와 `npm run build`로 확인합니다. `tests/baseline-search.ts`는 비교용 기존 검색 구현입니다. 가상 조문 8문항의 Top-1 평가는 특정 검색 오류를 재현하는 회귀 검사이며, 실제 법률 답변 정확도 점수가 아닙니다.

## 로컬 실행

```bash
npm install
cp .env.example .env.local
# .env.local에 GEMINI_API_KEY 입력
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## API 키

Google AI Studio에서 새 Gemini 키를 만들고 `GEMINI_API_KEY`에 넣습니다. 키는 브라우저 코드에 들어가지 않고 Next.js 서버 라우트에서만 읽습니다. `.env.local`은 `.gitignore`에 포함되어 GitHub에 올라가지 않습니다.

법제처 API는 미설정 시 공식 문서의 발표용 `OC=test`로 작동합니다. 안정적으로 배포하려면 국가법령정보 공동활용 사이트에서 이용 신청 후 발급받은 OC를 `LAW_API_OC`에 넣으세요.

## Vercel 배포

1. 이 저장소를 Vercel에서 Import합니다.
2. Project Settings → Environment Variables에 다음을 추가합니다.
   - `GEMINI_API_KEY`
   - `GEMINI_MODEL=gemini-3.1-flash-lite`
   - `LAW_API_OC` (정식 신청 전에는 `test`)
3. Deploy를 누릅니다.

API 키를 `NEXT_PUBLIC_...` 이름으로 만들거나 GitHub 파일에 직접 적지 마세요.

## 주의

이 앱은 교육용 검색 보조 도구이며 법률 자문이나 인허가 가능성을 확정하지 않습니다. 실제 프로젝트는 대상지의 용도지역·지구, 건축물 용도·규모, 지자체 조례와 관할 허가권자의 해석을 추가 확인해야 합니다.


## 독립 구현과 검증

Con-Reg의 공개 기능 흐름(질문 의도 분석→관련 법규 검색→실무 해석)을 비교 참고했습니다. 원본 Python 코드, 프롬프트, CSV 데이터는 복사하지 않았습니다. 이 프로젝트의 TypeScript 구현과 국가법령정보센터 API를 사용합니다. 기능 흐름의 유사성만으로 표절·저작권 문제가 없다고 보증하는 것은 아닙니다. 외부 소스를 직접 도입하면 라이선스와 출처를 확인해야 합니다.
